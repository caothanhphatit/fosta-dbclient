Support

Support Fosta Studio

Fosta Studio is free and open source under the GPL-3.0, with no account and no telemetry. It is built by one person, and every kind of help keeps it going.

Where donations go

  • Code signing, so Windows stops showing a SmartScreen warning for the installer.

  • Servers, such as the one behind this website.

  • Time to fix bugs and work through the roadmap.

Donating is optional. The app is free to use either way.

Help without money

  • Star it on GitHub

    A star helps other developers find the project. Open the repository

  • Report bugs

    Use the bug report form and paste the diagnostics the app copies for you. Open an issue

  • Share it

    Tell a colleague, mention it in your team chat, or write about how you use it.

  • Translate

    Improve a translation of this website, or add a language. How translations work

Donate

Scan a code with your banking or e-wallet app. Any amount helps.

Thank you for helping keep Fosta Studio free.
