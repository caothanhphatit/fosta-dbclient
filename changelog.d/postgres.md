- PostgreSQL is now a ready engine: a tree of databases, schemas, tables, views, materialized views, functions, sequences, types (enums, domains) and extensions; typed values (arrays, jsonb, uuid, numeric, timestamptz); keyset paging and exact or estimated counts; Stop that cancels the running statement on the server.
- PostgreSQL edits fail with a conflict instead of overwriting when the row changed since you loaded it: the grid sends the row's `xmin`, and tables without one (views, partitioned parents) are checked by the original values.
- PostgreSQL query tabs keep a transaction across runs, report the SQLSTATE, detail, hint and error position, and accept `postgres.explain` (`EXPLAIN (FORMAT JSON)`; with `analyze` it runs in a rolled-back transaction and is classified by the statement inside it).
