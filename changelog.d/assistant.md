- Every code block in the assistant panel has a Run button next to Insert and New tab, for SQL, MongoDB commands, Redis commands and the Elasticsearch / OpenSearch console. It runs as your own run under the workspace safety rules (confirmation, typed confirmation, blocked), shows up to 200 rows in a compact grid under the block with "Open in tab", and shows errors in the structured error panel.
- The assistant can run read-only queries itself to look at real data (one statement at a time, at most 50 rows, 10 seconds, cancelled when you press Stop). Anything that writes, changes the schema or administers the server is refused, and the assistant hands it to you as a code block instead. Each run shows in the chat as an expandable tool call and is written to the audit log.
- Settings → "Allow the assistant to run read-only queries" turns this on or off (on by default; the rows it reads are sent to your AI provider). Read-only and Production workspaces stay off unless Edit workspace → Assistant queries allows them.
- The assistant's schema tools work for every ready engine, including Elasticsearch and OpenSearch indices; on Redis they list at most 200 keys per database.
