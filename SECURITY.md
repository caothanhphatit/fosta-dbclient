# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/caothanhphatit/fosta-dbclient/security/advisories/new), not in a public
issue. Include the version, the edition (Windows installer, portable or web edition) and the steps to reproduce. You will get an
answer within a few days, and a fix is released as soon as it is ready; you are credited in the release notes unless you prefer not
to be.

## Supported versions

Only the latest release gets security fixes. The installed Windows app updates itself; the portable app and the web edition show when
a new version is available.
